# Lab Rescue Agent

Multi-agent certification lab recovery and readiness system for Microsoft AI Agents League.

## Goal

Help enterprise learners recover from failed hands-on certification labs, map failures to skill gaps, generate safe recovery plans, and produce grounded practice questions using synthetic documentation.

## Hackathon alignment

- Track: Reasoning Agents with Microsoft Foundry
- Architecture: local-first Python multi-agent workflow
- IQ layer: Foundry IQ grounded retrieval over synthetic lab and certification knowledge
- Data policy: synthetic demo data only

## Planned agents

- Lab Triage Agent
- Recovery Planner Agent
- Learning Path Agent
- Assessment Agent
- Study Plan Agent
- Manager Insights Agent
- Safety Verifier Agent

## Safety rules

- No real employee data
- No customer data
- No secrets in source control
- Recovery steps must include rollback and verification

Project skeleton created. Local runnable demo is next.
